# Autoria e instalação pela loja

O manifesto e o pacote da ferramenta identificam **Zirtuno** como autor. Na Chrome Web Store, o nome público do desenvolvedor é configurado separadamente na conta que possui a extensão.

No [painel de desenvolvedor](https://chrome.google.com/webstore/devconsole), use o perfil Chrome da Zirtuno e abra **Conta / Account**. No campo **Nome do editor / Publisher name**, informe **Zirtuno** e salve. Se o Google solicitar login ou confirmação de identidade, o titular deve concluir essa etapa no próprio navegador. O campo aparece abaixo dos títulos das extensões publicadas. [Documentação oficial](https://developer.chrome.com/docs/webstore/set-up-account).

Depois de uma futura publicação aprovada, a instalação e as atualizações poderão acontecer pela Chrome Web Store, sem extrair ZIPs e carregar pastas manualmente. Criar uma conta de desenvolvedor ou informar o autor no manifesto não publica a extensão. Nenhum pacote foi enviado, submetido ou publicado na loja nesta alteração. [Processo oficial de publicação](https://developer.chrome.com/docs/webstore/publish).
