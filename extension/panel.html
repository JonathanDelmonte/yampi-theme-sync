Como editar no computador

Extraia o ZIP e abra a pasta no VS Code, ou abra o arquivo .code-workspace. O README.md explica a estrutura; preserve .yampi-sync/ para comparar e devolver as alterações. Com Node 24 instalado, execute npm ci e npm run dev. Edite os arquivos de tema/.

Depois, volte a Enviar alterações e selecione a pasta extraída. Se preferir ZIP, execute npm run pack e selecione o ZIP indicado no terminal.

A prévia local informa se usa contexto capturado ou demonstrativo; recursos ausentes e limitações estão em preview/report.json. Confira o resultado também na Yampi.
