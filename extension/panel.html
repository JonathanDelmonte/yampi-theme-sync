Como editar no computador

Extraia o ZIP em uma pasta. Com Node 24 instalado, execute npm ci e npm run dev. Edite os arquivos de tema/.

Depois, volte a Enviar alterações e selecione a pasta extraída. Se preferir ZIP, execute npm run pack e selecione retorno-yampi.zip.

A prévia local usa dados fictícios e tem compatibilidade parcial. Confira o resultado também na Yampi.
